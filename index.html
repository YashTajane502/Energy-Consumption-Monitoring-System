    How the C++ System Works

    The original program is a menu-driven console app using C++ classes (Record, EnergyMonitor), a vector of records and file handling. This website is only a visual demo — it does not run the C++ code or read energy_data.txt.

    1Enter detailsDevice, date and units are typed in.
    2ValidateNon-empty device, valid date, units ≥ 0.
    3Assign IDNext ID = highest ID + 1.
    4StoreRecord is pushed into the vector.
    5Save to fileWritten to energy_data.txt.
    6AnalyzeStatistics and slab-based bill.
    Frontend demonstration · data is stored only in this browser (localStorage).
